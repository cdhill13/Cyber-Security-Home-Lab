# Cyber Security Home Lab

Personal cybersecurity laboratory designed to develop hands-on
experience in offensive security, networking, Linux administration,
and security automation.

## Objectives

- Develop practical penetration testing skills
- Strengthen networking fundamentals
- Develop Linux administration skills
- Practice web application security
- Build security automation tools with Python
- Document security findings and remediation

## Environment

- Kali Linux
- VirtualBox
- Linux
- Python
- Nmap
- Wireshark
- Burp Suite

## Lab Areas

### Networking
Network reconnaissance, service enumeration,
packet analysis, and TCP/IP fundamentals.

### Linux
System administration, permissions, users/groups,
processes, services, and privilege escalation.

### Web Security
HTTP analysis, authentication, authorization,
input validation, and vulnerability assessment.

### Security Automation
Python tools developed to automate security-related tasks.

## Methodology

Each lab is documented with:

1. Objective
2. Environment
3. Methodology
4. Tools
5. Evidence
6. Findings
7. Impact
8. Remediation
9. Lessons Learned
